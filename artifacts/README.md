# Artifacts

Artifacts are generated by specialist agents and remain drafts until their owning workflow records the required human approval. Before discovery outputs are published, `orchestrator-agent` resolves the project’s approved Confluence folder and Jira destination. Local paths remain stable regardless of publication target.

| Folder | Owning agent | Output |
|---|---|---|
| `prd/` | `prd-agent`, then `orchestrator-agent` | Confirmed `prd-<slug>.md` and final assembled `final-prd.md` |
| `research/` | `research-requirements-agent` | `requirements-baseline.md`, `open-questions.md` |
| `features/` | `feature-analyst-agent` | `feature-specification.md` and approved feature/epic breakdowns |
| `stories/` | `user-story-analyst-agent` | `user-stories.md`; approved stories may be published to Jira by `orchestrator-agent` |
| `architecture/` | solution and architecture-suite agents | `solution-architecture.md`, `solution-architecture-overview.md`, `security-architecture.md`, `tech-stack.md`, `high-level-design.md`, `low-level-design.md`, `architecture-validation.json` |
| `design/` | `uiux-designer-agent` | `ui-ux-specification.md` |
| `estimation/` | `estimation-cost-agent` | `estimation-cost-analysis.md` |
| `risk/` | `risk-compliance-agent` | `risk-register.md` |
| `test-strategy/` | `test-strategy-agent` | `test-strategy.md` |
| `development/<work-item-id>/` | `dev-orchestrator-agent` and development specialists | Optional greenfield `project-initialization.json`, requirements validation, implementation plan, tech-lead review, implementation evidence, unit-test report, code review, final verification, and `qa-handoff.md` |

Discovery and architecture artifacts use the metadata contract in `.claude/skills/product-discovery/SKILL.md`. An artifact whose `Human approval status` is not `APPROVED` remains a draft.

Development artifacts use `.claude/agents/dev-orchestrator-agent.md` schemas and are linked by `work_item_id` and plan checksum. New work must not create legacy root-level artifacts such as `01-jira.md` or `07-code-verification.json`.
